## api

Call an authenticated platform JSON API; no automatic mutation retries

```sh
fmx api <method> <path> [options]
```

- `--tenant <uuid>`: Tenant (default: configured tenant)
- `--data <json>`: JSON payload
- `--file <path>`: JSON file; - reads stdin
